# Humam Flayyes — Portfolio

Video editor · motion designer · VFX artist — هُمام فليّس

A portfolio styled like an editing timeline. It's plain HTML/CSS/JS with no build step, so it runs as-is on GitHub Pages.
GSAP (ScrollTrigger, SplitText) and Lenis load from jsDelivr.

## Update content

Edit **`projects.js`**. It's the only file you need: projects, reels, VFX breakdown, services, socials and email.
Put your video files in **`videos/`** (see `videos/README.md`). Any missing clip shows a styled "no signal" placeholder.

## Files

```
index.html      markup
css/style.css   styles
js/main.js      rendering + motion
projects.js     your content
videos/         your clips
```
